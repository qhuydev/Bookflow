# Definition of Done

Một ticket chỉ hoàn thành khi:

- Đáp ứng acceptance criteria.
- Không có thay đổi ngoài phạm vi.
- Code dễ đọc và không chứa secret.
- Có validation và error handling phù hợp.
- Test đã được viết hoặc cập nhật.
- Các kiểm tra liên quan thực sự đã được chạy.
- Tài liệu được cập nhật.
- Không phá vỡ tenant isolation.
- Migration có thể chạy tiến lên an toàn, nếu ticket có thay đổi database.
- Báo cáo rõ những kiểm tra chưa thể chạy và lý do.
